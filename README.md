# LorryTruck — грузовой автосервис в Домодедово (новая версия сайта)

Статический сайт (HTML/CSS/vanilla JS), публикуется через GitHub Pages из ветки main.

Источники данных (ничего не придумано):
- lorrytruck.ru — тексты главной, страница «Обслуживание автопарков», письмо руководителя, примеры ремонта и их фото, прайс каталога (243 страницы, 4088 позиций, `assets/data/prices.json`, цены «от»).
- Карточка организации на Яндекс Картах (id 51367159044) — рейтинг 4,9 / 409 оценок / 158 отзывов, отзывы, виды работ и техники, удобства, способы оплаты, нормочас 1250–3000 ₽, фото цеха.

Фото: собственные фото сервиса (lorrytruck.ru и Яндекс Карты), стоковые материалы не использовались.
Шрифты: Russo One, Golos Text, IBM Plex Mono (SIL Open Font License), подмножество символов сайта.
